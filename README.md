# Hira Case Telegram Bot

## Project Introduction

**Hira Case Telegram Bot** is a Telegram bot designed for managing and ordering mobile phone cases.

Hira Case is a Python-based Telegram bot developed for a mobile phone case store. Users can browse available cases based on their phone brand and model, select their desired product and color, manage their shopping cart, and place orders.

The project also includes an **Admin section** for managing products, phone models, inventory, and orders.

## Project Features

### Customer Features

* User registration and information management
* Browse products by phone brand and model
* View product details and prices
* Select case colors and models
* Browse and select custom designs
* Add products to the shopping cart
* Change product quantities
* Remove products from the shopping cart
* Place orders

### Admin Features

* Add new products
* Edit product information
* Delete products
* Manage phone models
* Manage product colors and inventory
